# ۰۱ — توضیح کامل سایت

## چیست؟

وب‌سایت شخصی/پورتفولیوی **میر خلیلی**، طراح گرافیک و هویت بصری، با زبان فارسی و چیدگان
راست‌به‌چپ (RTL) و سبک بصری **مینیمال تایپوگرافیک سوئیسی**: پالت کاغذ/مرکب/آجری، گرید دقیق،
تایپوگرافی درشت و فضای سفید سخاوتمند.

> **تغییر مهم در نگارش 005.2.2.0:** پروژه از این پس **تک‌نسخه‌ای CMS** است.
> نسخهٔ استاتیک Astro (پوشه‌های `src/` و `public/`) حذف شد و ریشهٔ ریپو دقیقاً
> محتوای `public_html` هاست است. این تصمیم برای ساده‌سازی نگهداری، امنیت
> (حذف `install.php`) و یکسان‌سازی تجربهٔ کارفرما گرفته شد.

**ویژگی‌های کلیدی CMS:**
- پنل ادمین تحت وب برای مدیریت همهٔ محتوا (بدون نیاز به ویرایش کد)
- دیتابیس MySQL با ۱۷ جدول و دادهٔ اولیهٔ کامل
- مسیرهای تمیز، سئوی پویا، فرم تماس پایگاه‌داده‌ای

## ساختار پوشه‌ها (ریشه = public_html)

```
.
├── index.php  work.php  project.php  about.php  services.php  contact.php  404.php
├── sitemap.php  robots.php  schema.sql  .htaccess  favicon.svg
├── inc/               ← هسته: db, helpers, data, header, footer (مسدود از بیرون)
│   └── config.sample.php  ← نمونهٔ پیکربندی (کپی به config.php)
├── admin/             ← پنل ادمین (login, index, projects, categories,
│                         services, resume, settings, messages)
├── assets/
│   ├── css/style.css  ← CSS کامپایل‌شدهٔ Tailwind (بدون بیلد روی سرور)
│   ├── css/src/input.css ← سورس Tailwind برای بازسازی اختیاری
│   ├── js/            ← main.js (سایت) و admin.js (ردیف‌های پویا)
│   ├── fonts/         ← وزیرمتن متغیر + Space Grotesk/Mono (خودمیزبان)
│   └── uploads/       ← تصویرهای نمونه‌کار + آپلودهای پنل
├── Docs/              ← همین مستندات (نگارش 005.2.2.0)
├── VERSION            ← شناسهٔ نگارش جاری (005.2.2.0)
└── CHANGELOG.md       ← تاریخچهٔ نگارش‌ها (QAVNS)
```

> نکته: فایل `inc/config.php` واقعی (حاوی رمز دیتابیس) در ریپو نیست و توسط
> `.gitignore` نادیده گرفته می‌شود؛ نمونه‌اش `inc/config.sample.php` است.

## پشتهٔ فنی

- **CMS**: PHP 8.1+ (PDO با `ATTR_EMULATE_PREPARES=false`)، MySQL/MariaDB `utf8mb4`، Apache با `.htaccess`
- **فونت‌ها**: وزیرمتن متغیر (خودمیزبان، ~۱۱۲KB) + Space Grotesk Variable و Space Mono برای اعداد/برچسب‌های لاتین
- **استایل**: Tailwind CSS v4 کامپایل‌شده؛ سورس در `assets/css/src/input.css` (بخش `@theme`)
- **اسکریپت‌ها**: جاوااسکریپت خالص (IntersectionObserver، ساعت تهران، منو، پیش‌نمایش شناور)
- **بدون Node روی سرور**: CSS از قبل کامپایل‌شده است؛ بازسازی فقط به‌صورت محلی و اختیاری

## صفحه‌های سایت عمومی

1. **خانه** — هیرو تایپوگرافیک سه‌خطی با انیمیشن پرده‌ای، نوار متحرک خدمات، فهرست شماره‌دار کارها با پیش‌نمایش شناور، بخش استودیو + آمار، فهرست خدمات، فراخوان پایانی
2. **کارها (`/work`)** — آرشیو با فیلتر دسته‌بندی سمت سرور (همه/هویت و لوگو/پوستر/کتاب و نشر/بسته‌بندی/کارت ویزیت/بنر/تایپوگرافی)
3. **کیس‌استادی (`/work/{slug}`)** — تصویر شاخص، جدول متادیتا، روایت پاراگرافی، گالری، پالت رنگ با کد هگز، اسپسیمن تایپوگرافی، معیارها، پروژهٔ بعدی
4. **درباره (`/about`)** — روایت شخصی، آمار، مسیر حرفه‌ای، ابزارها، جوایز
5. **خدمات (`/services`)** — کارت‌های خدمات با زیرآیتم‌ها + فرآیند چهارمرحله‌ای
6. **تماس (`/contact`)** — فرم با اعتبارسنجی و ذخیره در دیتابیس + اطلاعات استودیو
7. **۴۰۴** — صفحهٔ خطای هم‌سبک فارسی

## صفحه‌های پنل ادمین

ورود (`/admin/login.php`)، داشبورد، پروژه‌ها، دسته‌بندی‌ها، خدمات و فرآیند، رزومه و جوایز، تنظیمات سایت، پیام‌ها —
جزئیات هرکدام در [۰۴](04-admin-features.md).

## نصب و دیپلوی

ریشهٔ ریپو = `public_html`. روش نصب **بدون `install.php`** (ایمپورت `schema.sql` در phpMyAdmin + ساخت `inc/config.php` از روی نمونه + کوئری ساخت ادمین) در [۰۶](06-install-deploy.md) آمده است.
