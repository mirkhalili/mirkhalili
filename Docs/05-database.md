# ۰۵ — دیتابیس: جدول‌ها و ارتباط‌ها

تعریف کامل: `schema.sql` در ریشه (ریشه = public_html) — موتور InnoDB، charset `utf8mb4` / collation `utf8mb4_unicode_ci`.

| جدول | نقش | کلیدها/ارتباط‌ها |
|---|---|---|
| `users` | کاربران ادمین | `username` یکتا؛ `password_hash` (bcrypt) |
| `settings` | تنظیمات کلید/مقدار سایت | PK: `setting_key` |
| `socials` | شبکه‌های اجتماعی | `sort` |
| `categories` | دسته‌بندی نمونه‌کارها | `slug` یکتا (برای فیلتر آرشیو) |
| `projects` | پروژه‌ها/نمونه‌کارها | FK → `categories.id` (SET NULL)؛ `slug` یکتا؛ `published` |
| `project_services` | خدمات هر پروژه | FK → `projects.id` (CASCADE) |
| `project_palette` | پالت رنگ هر پروژه (hex+نام) | FK → `projects.id` (CASCADE) |
| `project_metrics` | معیارهای عددی هر پروژه | FK → `projects.id` (CASCADE) |
| `project_images` | گالری تصاویر هر پروژه | FK → `projects.id` (CASCADE) |
| `services` | خدمات استودیو | `sort` |
| `service_items` | زیرآیتم‌های هر خدمت | FK → `services.id` (CASCADE) |
| `process_steps` | مراحل فرآیند کار | `sort` |
| `stats` | آمار (سال تجربه و…) | `sort` |
| `timeline` | مسیر حرفه‌ای (رزومه) | `sort` |
| `awards` | جوایز | `sort` |
| `skills` | ابزارها/مهارت‌ها | `sort` |
| `messages` | پیام‌های فرم تماس | `is_read`، `created_at` |

## نکات طراحی اسکیمای

- **ترتیب نمایش** همهٔ جدول‌های فهرستی با ستون `sort` + `id` کنترل می‌شود (ترتیب پنل = ترتیب سایت).
- **حذف آبشاری**: حذف پروژه/خدمت، ردیف‌های فرزند را خودکار پاک می‌کند؛ حذف دسته پروژه‌ها را نابود نمی‌کند.
- **متن‌های چندپاراگرافی** (`projects.description`) با دو خط خالی جدا می‌شوند و در قالب با `preg_split` رندر می‌شوند.
- **فهرست‌هایPipe‌ای** در `settings` (مثل `hero_areas` و `marquee`) با `|` جدا می‌شوند.
- `updated_at` روی `projects` برای «آخرین ویرایش‌ها» داشبورد استفاده می‌شود.

## داده‌های اولیه (Seed)

- ۲۳ ردیف تنظیمات (متن‌های فارسی کامل سایت)
- ۴ شبکهٔ اجتماعی، ۷ دسته‌بندی (هویت و لوگو، پوستر، کتاب و نشر، بسته‌بندی، کارت ویزیت، بنر و بیلبورد، تایپوگرافی)
- ۸ پروژهٔ نمونه با خدمات/پالت/معیارها کامل (رُست، پوستر جشنواره، کتاب سی‌وسه‌پل، هم‌نوا، طلای سرخ، کارت ویزیت دیدار، بنر شهری کتاب، قلم کاشان)
- ۷ خدمت با ۲۸ زیرآیتم، ۴ مرحلهٔ فرآیند، ۴ آمار، ۳ ایستگاه رزومه، ۴ جایزه، ۶ ابزار

## ایمپورت

از نگارش 005.2.2.0 به بعد، `schema.sql` مستقیماً از طریق **phpMyAdmin → Import** ایمپورت می‌شود (بدون `install.php`).
راهنما: [06-install-deploy.md](06-install-deploy.md) گام ۳.


## تغییر دیتابیس در نگارش 007.2.3.0

ساختار جدول‌ها تغییر نکرده است. تنظیمات جدید در جدول key/value موجود `settings` ذخیره می‌شوند؛ بنابراین فایل مهاجرت یا schema جداگانه لازم نیست. در تغییرهای آتی که ساختار دیتابیس را عوض کنند، schema نسخه‌دار در `database/` قرار می‌گیرد.


در نگارش 008.2.4.1 ساختار دیتابیس تغییر نمی‌کند؛ فرم راه‌اندازی فقط ردیف `admin_setup_complete` را به `settings` اضافه می‌کند. فایل مهاجرت/schema جداگانه نیاز نیست.


## ساخت مدیر با SQL نسخه‌دار در 009.2.5.1

فایل نسخهٔ جاری [`database/010.2.5.2-create-admin.sql`](../database/010.2.5.2-create-admin.sql) برای درج اولین مدیر در جدول موجود `users` است. پیش از اجرا مقدار placeholder را با هش bcrypt تولیدشده توسط PHP جایگزین کنید. این عملیات جدول یا ستون جدید نمی‌سازد؛ schema ساختاری دیتابیس تغییر نکرده است. جزئیات: [راهنمای نصب](06-install-deploy.md).


در نگارش 010.2.5.2 فایل SQL ساخت مدیر با collation صریح `utf8mb4_unicode_ci` به‌روزرسانی شد تا با collation اتصال phpMyAdmin تداخل نکند. ساختار جداول همچنان بدون تغییر است.
