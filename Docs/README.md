## تغییرات نگارش 008.2.4.1

- فرم امن ساخت اولین مدیر، fallback برای مسیرهای اصلی، فونت محلی فارسی، تیتر هیرو کوچک‌تر و ردیف‌های فشرده‌تر
- schema دیتابیس تغییری ندارد


- کنترل محتوای صفحهٔ نخست و تیترهای صفحات اصلی از پنل، با قالب‌بندی امن پررنگ/کج (نگارش 007.2.3.0)
- جست‌وجوی نمونه‌کارها و بهبود اعتبارسنجی فرم تماس
- اصلاح خطای Parse در تابع همگام‌سازی ردیف‌های تکرارشونده
- بدون تغییر ساختار دیتابیس؛ schema جدید لازم نیست


- افزودن `.htaccess` ریشه برای rewrite مسیرهای تمیز، محافظت فایل‌های حساس، هدرهای امنیتی و HTTPS

- حذف کامل نسخهٔ استاتیک Astro (`src/`, `public/`, `astro.config.mjs`, `tsconfig.json`)
- حذف `install.php` — نصب اکنون دستی و امن‌تر (ایمپورت `schema.sql` + `inc/config.sample.php`)
- ریشهٔ ریپو = `public_html` (بدون پوشهٔ واسط `cpanel-site/`)
- به‌روزرسانی همهٔ اسناد به ساختار جدید
