# ۰۹ — راهنمای تولید و ویرایش محتوا

## افزودن یک نمونه‌کار جدید (پنل → پروژه‌ها → + پروژهٔ جدید)

1. عنوان فارسی و (اختیاری) لاتین؛ slug خالی بگذارید تا از عنوان لاتین ساخته شود
2. دسته را انتخاب کنید (اگر ندارید: دسته‌بندی‌ها → جدید)
3. خلاصهٔ یک‌جمله‌ای + شرح با **یک خط خالی بین پاراگراف‌ها**
4. تصویر شاخص (نسبت ۴:۳ یا ۱۶:۹، حداقل ۱۶۰۰px پهنا) + گالری اختیاری
5. ردیف‌های خدمات، پالت (هگز با `#`) و معیارها را پر کنید؛ ردیف خالی خودکار نادیده گرفته می‌شود
6. ترتیب نمایش = عدد کوچک‌تر یعنی بالاتر؛ چک‌باکس انتشار را بزنید → ذخیره

## ویرایش متن‌های سایت

پنل → تنظیمات: همهٔ متن‌ها (هیرو، درباره، استودیو، یادداشت‌ها) این‌جا هستند.
فهرست‌هایی مثل «حوزه‌ها» و «نوار متحرک» با کاراکتر `|` جدا می‌شوند.

## تصویرها

- آپلود از پنل به `assets/uploads/` می‌رود با نام تصادفی امن
- تصویرهای اولیهٔ قالب در همان پوشه‌اند؛ برای حذف، از بخش گالری پروژه یا File Manager اقدام کنید
- پوشهٔ `uploads/` توسط `.htaccess` داخلی از اجرای اسکریپت محافظت می‌شود

## چک‌لیست انتشار محتوا

- [ ] عنوان/خلاصه بدون غلط املایی و با لحن برند
- [ ] تصویر شاخص حداقل در دو اندازه (موبایل/دسکتاپ) بررسی شود
- [ ] پالت رنگ با کد هگز درست وارد شده باشد
- [ ] پس از ذخیره، صفحهٔ عمومی پروژه را در حالت ناشناس باز کنید
- [ ] فرم تماس و sitemap پس از انتشار پروژهٔ جدید تست شود
